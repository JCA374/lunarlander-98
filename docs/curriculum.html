Curriculum

Every run's stages: the world it flies, the reward it is paid, the check that ends the stage, the cap, and the outcome I expected, all written down before the stage starts. Checks always fly the real task with no help.

What the last project taught about curricula

Easy stages can erase a good starting agent: in the NEAT project a 90% agent fell to 52% after training in calm air, because the weights that read the wind sensor drift freely when the wind is zero. So when a run starts from a strong agent, every stage keeps 30–50% real-task flights (rehearsal) and every check flies the real task. From a weak start, a curriculum calm → steady push → gusts → turbulence → boulder works, with fading training wheels (a torque that pulls the lander upright and fades to zero). For the last few percent, the natural curriculum is hard cases: re-fly the seeds the agent fails on more often.
