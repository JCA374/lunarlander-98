Lessons

What the earlier projects taught, and what this one adds. Newest additions at the top of each list.

From this project

  • Goal met: PPO from scratch, 98.8% and 98.4% on two untouched blocks of 1,000 test flights.
  • The hard-case curriculum (30% of flights re-fly recently failed seeds) gave the biggest single gain: 92.7% → 96%+, boulder hits 5% → 2%.
  • Learning from every step beats learning from one number per flight: PPO from scratch 91.4% after 45 minutes vs 83–88% for the warm-started alternatives.
  • A confident copy is a cage: the behaviour clone barely explores, so RL from it barely improves.
  • Stage passes on 200+200 flights are passed by luck after enough tries; pick champions on 1,000+ selection flights instead.
  • Never let a finished curriculum stop a run silently (an idle hour), and never let a publisher autostash code (an hour of reverted files).
  • The 2×128 behaviour clone of pilot v2 flies as well as the pilot (83.5% vs 85.9% on the same 1,000 flights): the warm start is real, not a conversion bug.
  • Re-measured on 1,000 fresh flights with the fair boulder layout: pilot v1 72.2%, pilot v2 84.0%, the old clone 84.6%. The most common failure is coming to rest just outside the flags (6.6–6.9%), then crashes (4–5%) and boulder hits (3.5%).

From the NEAT project (lunarlander-curriculum)

  • Sensing beats network size: the clean wind sensor lifted the pilot from 75% to 86%.
  • Check that the task is fair: about 2% of boulder layouts were unwinnable until the layout was fixed.
  • A warm start is only worth it if training doesn't destroy it: NEAT's mutations wrecked trained networks (children averaged 70.5% from an 86% parent).
  • Few flights per evaluation make selection lucky: wind noise is large.
  • Determinism and resume bugs cost the most time: test them first.
  • Easy curriculum stages can make a strong agent forget: rehearse the real task.
  • Pay for what you want (landings), not for a proxy (game score).
  • Profile before rewriting: the physics was never the bottleneck.
